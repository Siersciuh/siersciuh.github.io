🎥 Test kamery — Discord Activity

Jeden plik, bez instalowania czegokolwiek. Kliknij przycisk i zobaczysz podgląd kamery oraz komunikat po polsku.

Krok 1 — Twoje Client ID

Wklej Application / Client ID z Discord Developer Portal. To jedyna rzecz, którą musisz zmienić.

Możesz też wpisać je na stałe w kodzie (na dole pliku, linijka const CLIENT_ID = ...). Pole powyżej ma pierwszeństwo.

Krok 2 — Kamera

Jeszcze nie próbowano włączyć kamery. Kliknij przycisk powyżej.

🛠 Diagnostyka (pokaż, gdy coś nie działa)

✅ Co musisz zmienić (cała lista)

  1. Client ID — w polu powyżej albo w kodzie w const CLIENT_ID.
  2. URL Mappings w Discordzie: Panel dewelopera → Twoja aplikacja → Activities → URL Mappings → dodaj: Prefix: /esm → Target: https://esm.sh. Bez tego Discord zablokuje ładowanie SDK.
  3. Adres Activity (URL): w tym samym panelu ustaw URL, pod którym hostujesz ten plik (np. link z tunelu do testów albo docelowy hosting).
  4. Nic więcej w kodzie. Przycisk, podgląd i komunikaty są już gotowe.

Jeśli kamera nie działa, przeczytaj dokładny komunikat pod przyciskiem — zawiera techniczną nazwę błędu (np. NotAllowedError) i polskie wyjaśnienie, co zrobić dalej.
